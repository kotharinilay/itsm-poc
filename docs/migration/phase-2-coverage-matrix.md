**Status legend**

| Status | Meaning |
|---|---|
| `MIGRATED_TO_RULE` | Lives as prose in a `.claude/rules/*.md` file; Claude applies it, no machine gate |
| `MIGRATED_TO_SKILL` | Lives as a repeatable procedure in `.claude/skills/` |
| `MECHANICALLY_ENFORCED` | A build/CI gate enforces it; no `.claude` rule text needed |
| `MIGRATED_AND_MECHANICALLY_ENFORCED` | Both: rule text tells Claude what to write, a gate catches violations |
| `NOT_APPLICABLE_WITH_REASON` | Does not apply to any component here; reason recorded |
| `REQUIRES_FUTURE_ENFORCEMENT` | Retained as a rule, but the gate it needs does not exist yet |

**Mech? column:** `Y` = a gate fails the build/CI today. `Partial` = a gate covers part of the rule. `N` = no mechanical gate exists today.
